# Apex Habitat 1.60.50

Security hardening of the Masar worker access token.

- Worker self-service links now expire after a set window; an old or leaked link stops resolving and the worker is asked for a fresh one.
- The personal access token is restricted to high-trust roles only; lower roles can manage the record without seeing the secret.
- The personal access token is kept out of the record's version history.
- The personal access token no longer travels in the page URL or page source; it is carried in a secure httpOnly cookie instead.
- Added a referrer policy and a rate-limit guard so the personal link cannot leak to third parties or be driven as a brute-force oracle.
