# Apex Habitat 1.60.55

You can now hand tracked assets over to accommodation with a checkpoint-controlled delivery.

- **Controlled delivery.** A tracked asset moves to accommodation only after it clears a three-checkpoint release gate.
- **On-site confirmation.** The receiver confirms with an on-site code before the asset is recorded as moved.
- **Full chain of custody.** Each delivery is written to the immutable asset movement record, so the handover is always traceable.
