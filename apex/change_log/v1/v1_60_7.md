# Apex Habitat 1.60.7

Added immutable posting ledgers so reports read fixed records that do not change retroactively.

- Maintenance cost ledger: one immutable row per completed work-order item, traceable to source, reversed not deleted.
- Cleaning compliance ledger: per-room compliance snapshot posted on each cleaning log.
- Facility asset movement ledger: every asset move recorded as a queryable, immutable from/to history.
- Safety finding ledger: each safety-round finding posted immutably with its status snapshot.
