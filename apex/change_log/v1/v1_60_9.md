# Apex Habitat 1.60.9

Rental Office now uses the native Address system (with a safe backfill); housing cleaning is now a daily system-of-record (auto-created cleaning logs).

- Rental Office now uses the native Address system, with a safe one-time backfill of existing offices.
- Housing cleaning is now a daily system-of-record: a draft Cleaning Log is auto-created for every active building each day.
- Each auto-created cleaning log is left for the supervisor to mark and submit, so a forgotten day shows as a clear audit signal.
