# Apex Habitat 1.60.42

Notification plumbing, Saudi National Address support, native bed-status colours, and an Arabic translation top-up.

- Unified notification-log writes behind a single shared helper so in-app alerts post consistently across the habitat engines.
- Added Saudi Post (SPL) National Address fields (short address, building number, district, secondary number) to the standard Address form, with format validation.
- Restored bed-status colour coding on the front desk and transfer board using native indicator pills (no custom stylesheet).
- Translated 62 previously-untranslated interface strings to Arabic, closing the outstanding i18n gap.
