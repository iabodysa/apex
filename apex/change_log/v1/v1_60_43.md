# Apex Habitat 1.60.43

Freelance accounting party and a settings re-engineering pass: deduction policy consolidation, fleet authority gates, and Apex retention/payment/company controls.

- Freelance master: a short-term contract-worker record, registered as a custom accounting Party Type so a freelance can be a payable party on a native Journal or Payment Entry.
- Salary-deduction configuration consolidated into a single Salary Deduction Policy (damage and housing-allowance rules), with a migration that moves any existing values without losing an enabled deduction.
- Fleet write-off and cost-recovery thresholds moved into settings, with delegation-of-authority approval gates: a regional tier below the threshold and an operations tier at or above it.
- Apex settings re-engineered: data-retention controls added, the default payment-method select retired in favour of a payment-routing target, and a shared company resolver introduced.
