# Apex 2.9.3

- Fix error — a handover could only be approved when the sending side had ticked the verification box before submitting, so the receiving side could never confirm the check they had actually made.
- Add feature — completing a service order now records the visit date, the notes, the photo and the supervisor's confirmation in the same step.
- Fix error — a route map that failed to draw once kept showing no route until the cache was cleared by hand.
- Fix error — the rental office form offered an address panel that was never used and had no connection to the office's own city, contact and phone.
- Add feature — a bulk vehicle action now refuses more than 50 vehicles at once, and a stock count more than 200 lines, instead of holding the screen.
