# Apex 2.1.16

The repository now ships the application and the application's own tests, and nothing else.

- The maintainer's own scanners and end-to-end scripts no longer ship with the application: the scripts and e2e directories are gone from the published tree.
- The continuous-integration steps that ran those maintainer tools were removed in the same change, so no lane is left calling a file that is no longer there.
- Comment policy, Arabic coverage, DocType dates and commit metadata are now enforced by the local pre-push hook rather than a shared lane, and the hook refuses rather than warns when a runner is missing.
- Nothing changes on screen: no DocType, report, portal or permission was touched.
