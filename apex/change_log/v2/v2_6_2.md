# Apex 2.6.2

Screens now say why a button is closed to you, and a refused link tells you so instead of quietly sending you somewhere else.

- Every disabled control on the portal now names the reason beside it, so a greyed-out button is an explanation rather than a dead end.
- Opening a link to a record you are not allowed to see now says so, where before it sent you to the list and looked like it had worked.
- A reissued handover code now works straight away; before, the earlier wrong attempts kept refusing the new code for several minutes.
- A cancelled payment request can no longer be paid.
- Reports now respect a permission narrowed to one document type, matching what the list already showed you.
- Arabic text across the portal is no longer letter-spaced, so the script joins the way it should.
