# Apex 2.1.3

Portals share one polling composable, seeding loops survive a bad row, and the hook wiring can be checked before a commit fails

- Route supervisor now polls through the same composable the worker portal uses, so it pauses while the tab is hidden, refetches on refocus and never overlaps requests
- A failing row in the role seeding and task-template migration loops no longer discards the rows already written in the same run
- An amended utility bill no longer carries the payment link of the document it amends
- The git hook wiring can be checked and repaired on demand instead of surfacing as a failed commit
- Generated portal type stubs are no longer tracked, so a rebuild cannot show up as a pending change
