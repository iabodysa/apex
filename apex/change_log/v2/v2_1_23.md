# Apex 2.1.23

The setup wizard can now create demo data to explore Apex with, and Apex Settings can remove every record it created.

- The last page of the setup wizard offers to create demo data: one sample accommodation site with rooms, beds, a resident and an open maintenance request. It is off by default, and the description says up front that the data can be removed later.
- Apex Settings carries a Remove Demo Data action that clears every record the demo created and nothing else. A submitted record is cancelled before it is deleted, so anything it posted is properly reversed rather than left behind.
- If a record cannot be removed, the removal reports which ones and keeps the demo login in place, so you can deal with them and run it again instead of being left with data nothing can select.
