# Apex 2.5.1

The type on every portal screen now uses a weight the brand face actually ships, and the housing, driver and worker screens wait, empty and fail the same way.

- Six portals asked for a font weight the licensed face does not ship, so the browser thickened the letters itself; they now use the real weight the brand file provides.
- The eight housing screens each drew their own heading, waiting and empty states; they now share one, so a heading no longer disappears while a list loads.
- The driver and worker portals carried their own copies of the waiting, empty and error screens; they now use the shared ones, and the status labels keep the brand green they had.
- A screen reader announced a loading list twice, because both the frame and the placeholder inside it claimed to be the status message.
