# Apex 2.5.0

Every print format now has a document on a fresh install, thirteen more labels read in Arabic, and a report link a role could see but not run now runs.

- The demo build creates a document for 24 of the 25 print formats, so a fresh site opens every one of them instead of fourteen.
- Thirteen labels that showed in English on print formats, report cards and workflow buttons now read in Arabic.
- Seventeen report links that raised a permission error on click now open for the roles that see them.
- A report removed from the app is now removed from sites that already had it.
- The depreciation summary counted rows by comparing translated text, so its figure changed with the language; it now counts on a stable key.
- A settled assignment no longer leaves its assignee on the document sidebar.
