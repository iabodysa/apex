# Apex 2.9.0

- Add feature — choosing a vehicle, a driver, a worker or a SIM now shows the plate, the name or the number instead of a record id like VEH-000042.
- Add feature — a transport request fills in the vehicle bound to the driver you chose, and a passenger row fills in the employee's name.
- Fix error — a new vehicle assignment proposed the OUTGOING driver, so submitting without noticing reassigned the vehicle to the person it was being taken from.
- Fix error — the Apex Core page listed 31 machinery tables an operator never opens; it now holds the four settings, and every record and chart has one home.
