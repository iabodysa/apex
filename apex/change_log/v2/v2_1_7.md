# Apex 2.1.7

A name lookup that could answer without checking the database is now refused before it ships

- Existence checks that pass a name the application computed at run time are rejected by the build, because such a check can return the name unchecked when it matches the document type
- The renaming step added in the previous release was the first thing the new check caught, and it now asks the database properly
- The checks that predate the rule are recorded, so their number can only fall
