# Apex 2.1.17

The release feed's own test no longer breaks when the release table grows.

- The test that proves a long release title is shortened for the notification feed was reading whichever release happened to be last in the list, so it broke on its own the moment the list outgrew the twenty-item feed, even though the shortening never stopped working.
- It now proves the rule directly, on a title one character over the limit and a title exactly at it, so the boundary itself is checked instead of a position in a list that keeps moving.
- Every shipped release title is also checked against the ceiling, whatever the list grows to.
- Nothing changes on screen: the feed already behaved correctly, only its test was wrong.
