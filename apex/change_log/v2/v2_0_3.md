# Apex 2.0.3

## What changed for users

- **Safer portal access.** Worker and driver access stays aligned with each person's active assignment.
- **More dependable sessions.** Portal access follows employment and clearance changes automatically.
- **Steadier mobile updates.** Worker and driver portals refresh cleanly to the current release.

## What changed under the hood

Security and reliability improvements.

## If you are updating an existing site

Run:

```bash
bench update
```

Keep the automatic backup enabled. Do not use `--reset` or `--no-backup`.
