# Apex 2.0.4

New Apex sites guide you through setup before adding starter accommodation supplies, while established sites keep their chosen Item Group organization.

## What changed for users

- **Guided setup from the first sign-in.** New sites open with the setup wizard ready for company and operational choices.
- **Accommodation supplies ready after setup.** Standard accommodation categories and items appear when first-time setup is complete.
- **Your Item Group organization stays yours.** Updates preserve valid custom parent groups chosen for the supplied accommodation categories.

## What changed under the hood

- Accommodation defaults use the standard Item Group lifecycle, keeping first-time setup and future updates predictable.

## If you are updating an existing site

1. Run `bench --site <site> migrate`.
2. Run `bench build --app apex`.
3. Clear the site's cache before operators continue setup.
