# Apex 2.1.10

The route supervisor screen gets the shared look, and the integration guide stops asking browsers to hold a password.

- Route supervisor now uses the same side menu, header and colours as the other supervisor screens.
- The integration help no longer tells a browser or phone app to carry an API secret, and shows the safe way instead. Existing sites get the corrected text.
- Internal notes can no longer slip into the public guides by mistake.
