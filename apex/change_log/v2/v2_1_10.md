# Apex 2.1.10

The published pages are checked like code, the route supervisor portal moves onto the shared design, and the upgrade runbook was rehearsed against a live site

- Internal notes and leftover markers can no longer reach the published pages unnoticed, and the route table's promise that routing has no hidden rules is now checked against the code
- The route supervisor portal uses the shared supervisor layout and the shared colours instead of its own copies, so a change to either reaches it
- The integration settings help no longer offers browsers and mobile apps a recipe that requires holding a secret, and existing sites receive the corrected text
- The application refuses to ship a link to a document that does not exist
