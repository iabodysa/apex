# Apex 2.3.4

The portal theme you pick now applies everywhere.

- **One theme, every portal** — Fleet, Fleet OS and the supervisor board follow the theme set in Portal Theme like the worker portals already did, instead of keeping a fixed palette of their own.
- **The theme survives a closed door** — the screen shown to someone without access to a portal now carries the same theme as the portal itself.
- Nothing you have recorded changes, and everyone keeps the access they had.
