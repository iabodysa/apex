# Apex 2.9.1

Bug fixes and stability improvements.

- **A maintenance request opens with its issue type blank.** The field arrived already set to Electrical, so a request saved without a second look carried a type nobody chose. You pick the type yourself, and the value the room or the request would have supplied now comes through.
- **A driver who has no employee record sees his sections empty, not refused.** Accommodation, custody and requests showed him an access-denied screen; they now show the same empty state every other section shows when it has nothing to display. Nothing he can reach has widened.
- **A portal device registration is visible only where it belongs.** The list of registered notification devices was readable in full from the portal side; it is now closed there, and opening a single one was already refused. No registration was changed and no one needs to sign in again.
- **Nothing already recorded is changed.** Requests and work orders saved before this update keep the issue type they were saved with.
