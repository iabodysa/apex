# Apex 1.47.6

Removed an obsolete onboarding leftover. No active feature change.

## What changed for users

- **Removed the orphaned "Habitat Operations Setup" onboarding.** It was the
  original single Habitat onboarding, superseded in v0.9.1 by the focused
  "Accommodation Go-Live" and "Safety Readiness" onboardings, and its workspace
  was removed when Setup was consolidated into Apex Core — so it was surfaced by
  nothing.
- Deleted its four exclusive steps (create site, create building, add rooms/beds,
  configure settings); the two steps it shared with the live onboardings are kept.
- Trimmed six now-dead onboarding strings from the Arabic translation file.

## If you are updating an existing site

- Run `bench migrate`. No data change. (On a site upgraded before this release the
  old Module Onboarding DB record is harmless and referenced by nothing; a clean
  reinstall drops it.)
