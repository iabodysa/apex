# Apex Habitat 1.54.3

Worker portal (Masar) fixes: a correct landing tab and active-state highlight, real session and permission error handling, and Arabic-localized status values.

- The portal's bottom Accommodation tab is now labeled and highlighted correctly; the landing tab no longer stays lit on every screen.
- A revoked, expired, or rate-limited session now shows a clear error with a retry, instead of a misleading empty 'nothing here' state.
- Status, request-type, category, and priority values now display in Arabic in the Arabic interface.
- Added the Arabic web font, international WhatsApp links, a larger language-toggle tap target, and minor navigation polish.
