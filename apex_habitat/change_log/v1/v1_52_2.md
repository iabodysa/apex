# Apex Habitat 1.52.2

Apex 1.52.2 — a migrate-stability fix, the Accommodation Site native address, an email master switch, and the Arabic translation backlog cleared.

- Migrate no longer fails with a "document is currently locked" error: the Role Profile was being re-imported as a fixture on every migrate, which left a stale lock whenever no background worker was running. Role Profiles now install only through their idempotent seeder (all seven still ship on fresh and existing sites); the redundant fixture file was removed.
- Accommodation Site now uses Frappe's native Address record (the same widget as the building), with a one-time, idempotent backfill that creates an Address from each site's existing city/district.
- New "Enable Email Notifications" master switch in Habitat Settings, OFF by default — a single kill-switch so the app sends no outgoing email until the site's mail is configured and the switch is turned on; the lone direct email send (the finance cost-center memo) now honors it.
- Arabic translations: the missing-translation backlog was cleared, with format placeholders preserved.
