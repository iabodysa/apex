# Apex Habitat 1.53

Configurable payment routing, app-wide settings, canonical workspaces, model-integrity normalization, a deep layout pass, and verified bug fixes.

## 1.53.3

_Form-layout review of the remaining core forms completed (council-reviewed, layout-only)._

- Eight more core forms were re-laid-out for clarity: Safety Inspection Report, Building License, Salis Vehicle, Salis Driver, Transport Request, Fuel Request, and Rental Settlement (Dispatch Trip was already optimal).
- System and audit fields were isolated into their own collapsed tabs or sections, related fields grouped by purpose, and short fields packed into denser columns.
- This completes the layout review of all core forms; every change is layout-only — no field, validation, or permission was altered.

## 1.53.2

_Five core forms re-laid-out for clarity (council-reviewed)._

- Five core forms — Accommodation Assignment, Checkout, Lease, Maintenance Request, and Custody Issue — were re-laid-out for clarity: fields grouped by purpose, audit and system fields isolated in collapsed System tabs, and short fields packed into denser columns.
- Long values (notes, tables, attachments) now take their own full-width rows instead of being cramped beside short fields.
- The forms behave identically and simply read better. One exception to layout-only: Accommodation Checkout's sensitive financial fields (cost centre, damage deduction, linked additional salary) were also gated to a higher permission level (permlevel), so only authorised roles see them.

## 1.53.1

_Salis now separates vehicle custody from worker transport, plus a driver-stop fix._

- Salis cleanly separates vehicle CUSTODY (a person receives a company vehicle — handover, fuel, maintenance) from worker TRANSPORT (moving workers by bus or taxi), matching how the two are actually operated.
- A transport request is now classified by trip type — site transport, inter-city relocation, or administrative trip — instead of a workers-versus-representatives split; existing requests migrate automatically.
- The two Salis workspaces were re-split into Worker Transport (Masar) and Fleet & Vehicle Custody.
- Cancelling an older Driver Stop no longer un-stops a driver that a later, still-active stop is holding.

## 1.53.0

_Configurable payment routing, app-wide settings, canonical workspaces, model-integrity normalization, a deep layout pass, and verified bug fixes._

- New configurable Payment Router: a finance-approved payment request becomes the chosen payment document via an admin-defined field map, replacing the inert default-payment-method setting.
- App-wide finance settings moved into a new Apex Settings, and Building License gained its proper amendment (renew) chain.
- All twelve workspaces re-ordered to one canonical layout — a single primary chart, then shortcuts, number cards, and grouped links.
- Data entry normalized: forty-seven link fields now auto-fill from their source record instead of being re-typed.
- Deeper form layout on twenty-three DocTypes — system and audit fields isolated, related fields grouped, short fields packed into denser columns.
- Fixed twelve verified correctness bugs across driver clearance, lease payment generation, transfer and stop lifecycles, and request conversion.
