# Apex 1.45.10

Clearer Arabic across the desk, tidier workspace titles, and a few internal cleanups.

## What changed for users

- **The Arabic desk reads more professionally.** Forty translations were refined to proper
  Modern-Standard "white-language" wording — for example payroll uses "خصم" (deduction) instead of
  "حسم" (a price discount), a finance sign-off is "إقرار" not "اعتراف", "نزيف التكلفة" became the
  standard "هدر التكلفة", and the Next/Back wizard arrows now point the correct way for right-to-left.
- **Workspace section titles now show in Arabic.** Titles that used an "&" (e.g. "Residents & Rooms",
  "Costs & Settlement") were not being translated because the "&" broke the match; they now read
  "Residents and Rooms", "Costs and Settlement", etc., and translate correctly.
- **Settings label tidied** — "Habitat Settings" no longer shows a redundant "(Habitat)" in Arabic.

## What changed under the hood

- 40 `ar.csv` entries refined to white-language; 9 workspace labels de-"&"-ed across 5 workspaces
  (with `modified` bumped so they re-import); the "(Habitat)" parentheticals removed.
- Closed audit minors: a lifecycle-order comment (Masar Worker Token), the Salis Settings seed now
  also runs on migrate so upgraded sites get new default keys, and a stale role-merge comment corrected.
- Added regression tests for four previously-untested controllers (Vehicle Category, Wash Platform,
  Fuel Platform, Salis Portal Theme) and filled two empty test stubs (Occupancy Snapshot, Stock Ledger).

## If you are updating an existing site

- Run `bench migrate` then `bench clear-cache` so the refreshed labels and translations load.
