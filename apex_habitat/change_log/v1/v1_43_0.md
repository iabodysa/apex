# Apex 1.43.0

Report correctness from the KB-grounded audit (Phase 3, reports).

## What changed for users

- **Housing Supervisor Report counts all active maintenance.** Maintenance
  requests in the Assigned and Reopened states are now counted as open (they were
  previously dropped from both the open and closed tallies), so the open
  maintenance figure no longer undercounts. Resolved and Closed are both counted
  as closed.
- **Two cost reports no longer silently cut off results.** Accommodation Cost
  Distribution and Accommodation Ledger Summary now require a From/To date range
  and return every matching row in that window, instead of silently stopping at
  the first 1,000 / 5,000 rows.

## What changed under the hood

- M-15 `housing_supervisor_report._maintenance`: open set is now
  Open/In Progress/Assigned/Reopened; closed set is Resolved/Closed.
- M-16 `accommodation_cost_distribution`: removed `limit_page_length=1000`
  (now `0` = no limit), added a mandatory `posting_date` range (server-side
  `frappe.throw` when absent), and added required `from_date`/`to_date` filters
  with 30-day defaults to the report JS.
- M-17 `accommodation_ledger_summary`: removed `limit_page_length=5000`,
  made the existing `from_date`/`to_date` mandatory (server-side throw + `reqd`
  filters with defaults).
- Tests: `test_reports` now exercises both reports with a date range plus a
  "requires date range" rejection case; `test_qa_probe_systems` tolerates the
  intended empty-filter rejection for date-bounded reports.

## If you are updating an existing site

- Run `bench migrate`, then `bench build` and `bench clear-cache` (the report
  filter JS changed).
