# Apex 1.43.0

Accuracy fixes in your housing and cost reports.


- **Open maintenance counts are accurate** — the Housing Supervisor Report now
  counts every active request, so the open figure no longer reads low.
- **Cost reports return every row** in the date range you pick, instead of
  stopping partway; pick a From and To date to run them.
- **Your existing data is untouched** — only how the reports tally changed.
