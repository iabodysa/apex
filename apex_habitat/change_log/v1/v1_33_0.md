# Apex 1.33.0

A new Arrivals Desk takes a worker from the building gate all the way to a bed, custody, an arrival card, and transport — all on one screen.


- **One building-first screen.** Pick a building and its live rooms-and-beds map appears beside a worker list. Search for an existing worker, or register a brand-new arrival by passport right there — the desk creates a temporary arrival record, never an Employee.
- **House with one click.** Click a free bed to place the selected worker. When a room is full, an over-capacity button adds them to a clearly marked temporary bed, capped by the building's overload limit. Everyone you house this session collects in an arrivals cart.
- **Custody, card, and transport in side panels.** Hand custody to each housed worker inline, issue the arrival QR link and print a welcome slip, and send several workers on one transport request — no pop-ups, all on the same screen.

After updating, the Arrivals Desk appears under the Accommodation workspace.
