# Apex 1.41.0

Correctness & security hardening from the KB-grounded audit (Phase 2, part 1).

## What changed for users

- **Custody-damage payroll deductions no longer fail silently.** If the Additional
  Salary deduction can't be created when a Custody Damage Assessment is submitted,
  the submit now stops with the error instead of completing with no deduction.
- **Auto-link of temporary workers is more robust.** A failure writing the
  informational comment no longer rolls back the (successful) link of a Temporary
  Worker to their Employee.
- **Tighter access control.** The Internal Auditor can no longer delete Occupancy
  Snapshots (read-only as intended), and two write actions (issue Masar worker
  link; mark a material transfer received) now require proper permissions / POST.

## What changed under the hood

- M-1 `custody_damage_assessment.on_submit`: removed the try/except that swallowed
  the Additional Salary failure (and the in-hook rollback that corrupted the
  submit) — failures propagate and abort the submit atomically.
- M-2 `temporary_worker_link`: the cosmetic add_comment failure now `log_error`s
  WITHOUT rollback (was undoing the re-point + cost back-dating + status=Linked).
- M-3 removed `delete` from the Internal Auditor DocPerm on Accommodation Occupancy
  Snapshot. M-7 `issue_worker_link` is now `methods=["POST"]`. M-8 `mark_received`
  gates on `has_permission(..., "write", doc=doc)`.
