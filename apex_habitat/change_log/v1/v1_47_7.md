# Apex 1.47.7

An internal project-structure tidy-up. No behavior change.

## What changed for users

- **No visible change.** Identical features, screens, and data — only the source
  layout moved to match the standard Frappe/ERPNext convention.
- Shared utilities moved from the Habitat module to the core module
  (`apex_core/utils/`).
- The data-driven setup loader and all install seeders are now grouped under
  `apex_core/setup/` (loader + `data/` + `seeders/`), instead of a separate
  `tools/` folder and seeders scattered across modules.
- Every import, hook, and test reference was repointed and verified
  (`bench build` + `bench migrate` + the seed tests all pass).

## If you are updating an existing site

- Run `bench migrate`. No data change.
