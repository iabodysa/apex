## 1.17.0

_You can now run Apex as the backend for your own front-end or another app, driven over a clean, token-secured connection._

- **Connect any front-end to Apex.** A new Integration Settings page lets you install Apex as a backend and drive it from your own app or website over a token-secured connection, with a step-by-step guide to follow.
- **Token, app-connection and webhook tools in one place.** The controls for issuing access tokens, registering connected apps, and sending live updates to other systems now sit together, so you set up an integration without hunting.
- **A tidier configuration hub.** The Apex Core workspace is reorganized into clear sections — Settings, Integration, Habitat setup, Salis setup, and Console — so you find the right control faster.
- **Working help links.** What's-New and the help menu now open the current configuration hub instead of pages that were removed.
