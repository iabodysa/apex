# Apex 1.45.8

A small correctness fix for the Movement KPI report plus wider Arabic coverage.

## What changed for users

- **The Movement KPI Summary now counts the full selected month.** Previously, picking a date range
  that started mid-month silently dropped that whole month's fuel-consumption figures; the report now
  includes the entire month its dates fall in.
- **More of the desk reads in Arabic** — 13 more field labels and option values (e.g. "Stop",
  "Service Details", "Temporary (Over-Capacity) Bed", and status options like Received/Started/
  Transferred) now translate.

## What changed under the hood

- `movement_kpi_summary`: the `period_month` filter (a YYYY-MM field) is now compared against
  YYYY-MM-truncated bounds, fixing the partial-month exclusion.
- `checkout_pending_clearance`: removed an unused `assignment` field from the query.
- Added 13 `source,Arabic` rows to `translations/ar.csv` (4 field labels + 9 Select options).

## If you are updating an existing site

- Run `bench migrate` then `bench clear-cache` (so the new translations load). No data change.
