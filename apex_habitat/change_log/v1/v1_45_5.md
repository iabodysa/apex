# Apex 1.45.5

A reliability fix for the Action Inbox so it can never error on a leftover record
from a removed document type.

## What changed for users

- **The Action Inbox no longer shows an error** when an old approval is left over from
  a document type that has since been removed or renamed. Those stale approvals are now
  hidden from the inbox and cleaned up automatically.
- No change to your real pending approvals or tasks — only the broken leftovers are removed.

## What changed under the hood

- The inbox aggregation now skips Open Workflow Actions whose reference DocType no longer
  exists, so the desk never tries to load transitions for a deleted controller (which
  previously raised an ImportError and 500'd the page).
- The daily orphaned-Workflow-Action cleanup gained a "Case C" sweep that deletes Open
  actions for any reference DocType that no longer exists (or has no table) — these have
  no active Workflow to drive the existing per-workflow cleanup.
- Added behavioural regression tests covering both the inbox skip and the cleanup sweep.

## If you are updating an existing site

- Run `bench migrate`. The daily cleanup will purge any leftover orphaned approvals on its
  next run; nothing else to do.
