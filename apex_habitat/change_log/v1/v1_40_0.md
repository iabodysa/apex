# Apex 1.40.0

A dedicated "My Work" workspace — a focused, enterprise-style landing for each
user's pending actions, near the top of the desk sidebar.

## What changed for users

- **A "My Work" home.** A new workspace called "My Work" sits near the top of the
  sidebar and opens on the things waiting for you: a live "Pending My Action"
  count and a one-click shortcut into the Action Inbox where you Approve/Reject.
- **The count card now has a home of its own.** Previously the "Pending My Action"
  card lived only as one tile on the Apex Core admin workspace; it now anchors a
  dedicated personal work hub (the Apex Core card stays too).

## What changed under the hood

- New `is_standard` Workspace `My Work` (module Apex Core, public, `sequence_id` 5
  so it surfaces near the top): content = a "My Work" header + the "Pending My
  Action" Number Card + a Page shortcut to `action-inbox`. Imported by
  `bench migrate`. Labels already in `ar.csv`.

## If you are updating an existing site

- Run `bench migrate`, then `bench build` and `bench clear-cache`.
