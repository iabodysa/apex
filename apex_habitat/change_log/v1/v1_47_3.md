# Apex 1.47.3

An internal naming-metadata tidy-up. No behavior change.

## What changed for users

- **No visible change.** Document IDs are generated exactly as before.
- Seven DocTypes (Accommodation Bed, Accommodation Room, City, Fuel Daily Log,
  Salis Driver, Salis Vehicle, Trip Fulfilment Ledger) now carry the `naming_rule`
  that matches their existing `autoname`, so the desk Naming tab shows the correct
  rule instead of a blank field.
- A release-hygiene test now guards this: any DocType that sets `autoname` but
  leaves `naming_rule` empty — or sets a rule that contradicts the autoname style —
  fails CI.

## If you are updating an existing site

- Run `bench migrate`. No data change. (If the metadata does not refresh on an
  in-place migrate, a clean reinstall picks it up — the previous values were
  future-dated, which can make Frappe's import skip the file.)
