# Apex 1.45.4

A follow-up to 1.45.3 that makes the Movement (Salis) dashboards appear in full on a
brand-new install, not only after the first upgrade. No data change.

## What changed for users

- **The Workers Transport dashboard now appears immediately on a fresh install.**
  Previously it (and a few dashboard tiles) only showed up after the site's first
  `bench migrate`; now every Movement dashboard is present right after install.
- **No behavior change** for existing sites — your dashboards and any edits are untouched.

## What changed under the hood

- The Salis dashboard seeders now run in the install-time `after_sync` phase, which
  executes after the dashboard charts and number cards have been imported — so the
  dashboards can link the charts/cards they reference instead of skipping them.
- They continue to run on every `bench migrate` as well, keeping upgrading sites in sync.

## If you are updating an existing site

- Run `bench migrate`. Nothing to do beyond that — the change only affects how a fresh
  install orders its dashboard seeding.
