# Apex 1.45.4

The full set of Movement dashboards now appears on a brand-new site.


- **Every Movement dashboard is present from the start.** The Workers Transport view and its tiles now appear on a new install, not only after a later update.
- **Nothing changes for existing sites.** Your dashboards and any edits you made stay exactly as they are.
- **No data is affected.** This adjusts only how a fresh install sets up its dashboards.
