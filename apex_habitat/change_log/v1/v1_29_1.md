# Apex 1.29.1

Three native-first cleanups — using what Frappe already provides instead of custom code.

## What changed for users

- **Rent-due reminder is now a standard notification.** The monthly "rent payment
  unpaid" reminder is a native Frappe Notification on the rent schedule (fires per
  unpaid row on its due date), replacing a custom monthly scanner. Enable it and
  set email as with the other notifications.
- **Room-label print works on new installs.** The accommodation room-label print
  format now ships as a standard format, so it is available on a fresh site.
- **Consistent worker-link dialog.** The "share worker link / QR / WhatsApp"
  dialog now comes from one shared place, so it behaves identically wherever it
  appears (worker token, assignment, arrivals desk).

## What changed under the hood

- Removed the `monthly_rent_due_alert` scheduler in favour of an `is_standard`
  Notification (`Habitat - Rent Payment Due`). Flipped the room-label print format
  to `standard:Yes`. Consolidated three copy-pasted JS helpers into
  `public/js/masar_worker_link.bundle.js` wired via `app_include_js`.

## If you are updating an existing site

- Run `bench migrate`, then `bench build` and `bench clear-cache`.
