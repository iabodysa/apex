# Apex Habitat 1.54.13

Fix the Fleet dashboard cards failing to render.

- The /fleet board threw a script error ("cannot read properties of undefined") and showed no vehicle cards.
- Cause: the dashboard API returned a vehicle's current driver as a partial record, missing the project and date fields the card reads.
- The API now returns the current driver in the same full shape as a custody-history entry, so every card and detail panel renders.
