# Apex 1.50.0

The Action Inbox is now a full **My Work Center** (Path A).

## What changed for users

- **One screen for everything that's yours.** The page (still at *My Work →
  Action Inbox*) now shows five sections: documents **awaiting your action**
  (workflow approvals with inline Approve/Reject + your assigned tasks), **your
  open submissions**, **what closed in the last 48 hours**, and **your
  notifications**.
- Every section is **strictly yours** — read with your real permissions
  (`owner == you`), so it never reveals another person's documents, even for a
  user who can read everything.
- Each row links straight to its document; approvals and task-close still use the
  native Frappe workflow endpoints (no custom write path, no pop-up).
- All new labels are Arabic-translated; the page title is now "My Work Center".

## If you are updating an existing site

- Run `bench migrate`, then `bench build`. No data change.
