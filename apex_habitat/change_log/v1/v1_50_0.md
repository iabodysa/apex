# Apex Habitat 1.50

Your work inbox is now a full My Work Center — one screen for everything that's yours.

## 1.50.28

_Changelog hygiene: drop the redundant per-entry section heading._

- Removed the section heading from all changelog entries (current + archive); bullets read directly under the summary.
- Updated the changelog template to stop emitting that heading (the rule).
- Cosmetic only; the native changelog popup is cleaner.

## 1.50.27

_Room Setup: page styles moved to native room_setup.css (Frappe page convention)._

- Moved the wizard CSS from a JS-injected <style> to a sibling room_setup.css, auto-loaded by Frappe (same convention as action_inbox.css).
- Removed the _inject_styles method; no behavior change.
- Follows the framework Desk-page asset convention (page.js + page.css + page.json).

## 1.50.26

_Fix: native Address widget on Building now renders (controller onload was missing in 1.50.23)._

- Added controller onload -> load_address_and_contact so the Address widget populates linked addresses and the New Address button (1.50.23 shipped the field + JS but not the server onload, so it rendered empty).
- Legacy address field is now read-only (visible) instead of hidden, so existing addresses stay visible until the backfill migration.
- Verified: __onload.addr_list is populated.

## 1.50.25

_Building: Google Maps link is a clickable URL field (no API, no key)._

- google_maps_url renders as a clickable link — paste any Google Maps share URL and open the location directly from the form.
- No paid Maps API or key required — the simplest native approach.
- Lat/long + embedded map can be layered on later if needed (tracked in todo).

## 1.50.24

_Room Setup: floor_type now drives floor numbering (B/G/R), not a cosmetic label._

- Basement rooms get B-codes (below ground), Ground = G, Roof = R, middle floors stay numeric (e.g. JED1-B101 / JED1-G01 / JED1-201 / JED1-R01).
- Floors are ordered bottom-to-top by type (Basement -> Ground -> Middle -> Roof) in both the generator and the wizard.
- The Room Setup wizard shows the functional floor code per floor block.

## 1.50.23

_Accommodation Building: native Address widget (Address DocType) in the UI._

- Added the native Address widget (address_html) via the standard Address & Contact pattern — create and link Address records.
- Legacy free-text address field hidden (data kept; backfill + removal to follow).
- Building form renders linked addresses for saved buildings.

## 1.50.22

_Arabic translations for the Room Setup wizard page._

- Translated the Room Setup page strings: step labels, floor/room type labels, bed steppers, and approval messages.
- Floor type options (Ground, Middle, Roof, Basement) and the Setup Rooms action are localized.
- i18n only; no behavior change.

## 1.50.21

_Remove the legacy preset/table room generator from the building form._

- Removed the 'Quick Room Setup' dialog (floor presets) and the 'Generate from Table' button from the Accommodation Building form.
- Room creation now goes through the new Room Setup wizard page (Setup -> Setup Rooms).
- Deleted the unused preset/wizard client code (~480 lines).

## 1.50.20

_New Room Setup wizard page: staged floor -> room-type -> beds -> approve flow._

- New 'Room Setup' page (opened from the building Setup menu): define floors with floor type, set each room's type, set bed counts with mobile +/- steppers, then approve to create the rooms and beds.
- Reuses the existing safe room/bed generator (one transaction) and adds a floor_type field to the floor plan.
- Normal-DOM, mobile-friendly Frappe page (no shadow DOM); replaces the old preset/table flow (removal follows).

## 1.50.19

_Fix: Accommodation Building Connections were hidden by the form dashboard reset._

- The building form's custom dashboard called frm.dashboard.reset(), which hides the native Connections (linked-document groups); the connections are now re-rendered after the custom indicators.
- Rooms, Beds, Leases, Residents and other linked records appear in the building Connections again.
- Client-side rendering fix only; no data or schema change.

## 1.50.18

_My Work: restore scoped Quick Lists (Pending Approvals / My Tasks / Mentions); fix Financials translation._

- My Work shows three native Quick Lists — Pending Approvals (Workflow Action), My Tasks (ToDo), Mentions (Notification Log) — with number cards and the Action Inbox shortcut (three native surfaces).
- ToDo and Notification Log are per-user scoped via permission_query_conditions, so regular users see only their own rows.
- Corrected the Arabic translation of the Financials tab.

## 1.50.17

_Native DocType Connections across core hubs — related records now surface on each entity's form._

- Accommodation Building shows grouped Connections: Rooms & Beds, Residents, Contracts, Maintenance & Facilities, Safety, Custody, Cleaning, Utilities.
- Added/expanded native Connections on Accommodation Room, Bed, Site, Assignment, Custody Article, Dispatch Trip, Route Plan, Transport Request, Fuel Quota, Rental Office.
- Excluded derived ledger/snapshot links so the Connections tab lists only navigable entities; Arabic translations added for the new connection group labels.

## 1.50.16

_My Work: drop unscoped Quick Lists; keep number cards + Action Inbox shortcut (per-user correctness)._

- A Workspace Quick List filter cannot scope to the current user, so for privileged users it showed everyone's tasks/records on a personal My Work page.
- My Work now ships native number cards + a shortcut to the Action Inbox page, which is correctly per-user scoped (uses session.user).
- Updated My Work workspace tests to the native design (no custom block; Action Inbox shortcut required; no quick lists).

## 1.50.15

_Legacy Floor Plan grid on Accommodation Building is now read-only — managed by the Room Generator wizard._

- The Floor Plan child grid on the building form is read-only; floors are added or changed via the Room Generator wizard.
- Prevents manual edits that bypass the wizard safe numbering and capacity rules.
- The wizard still populates the grid programmatically; existing floor data is unchanged.

## 1.50.14

_My Work workspace rebuilt with native widgets — removed the non-rendering custom HTML block._

- My Work now uses native Frappe widgets only: number cards, an Action Inbox shortcut, and live Quick Lists (Pending Approvals, My Tasks, Mentions).
- Fixes the workspace showing only cards: the embedded shadow-DOM work center did not render reliably; the native Action Inbox page (same get_my_work data) is the interactive surface.
- Retired the My Work Center custom HTML block seeder and its after_install/after_migrate hooks.
- Arabic translations added for the new workspace labels.

## 1.50.13

_Room setup wizard: floor presets, per-floor code prefixes, and safe bed-capacity reduction._

- Floor presets (All Worker, Worker+Supervisor, Worker+Office/Storage, Driver, Mixed) and copy-floor-to-next to speed up building setup.
- Optional per-floor code prefix for room/bed numbers; building abbreviation locks once rooms exist to protect already-generated codes.
- Safe capacity reduction: empty surplus beds are retired to Out of Service after confirmation; rooms with occupied surplus beds are blocked instead of silently changed.
- Arabic translations added for all new room-setup strings.

## 1.50.12

_Fix building DocType: remove lease fields that belong on Accommodation Lease_

- Remove rent_due_day (dead field — never read by any code; lease due day is implicit in first_payment_date on the lease)
- Remove lease_start_date, lease_end_date, lease_renewal_status from Building — Accommodation Lease is the authoritative source; rewrite lease_expiry_watchlist() to query it directly

## 1.50.11

_Fix My Work Center custom block not updating after source edits_

- Seeder now compares a SHA-256 hash embedded in the block HTML; updates html+script on every migrate when source changes
- Removes the existence-only guard that prevented browser from ever receiving seeder updates after first install
- Hash stored as HTML comment in the html field — no schema change required

## 1.50.10

_My Work is now a universal work center for every system user._

- Opening the My Work workspace now shows a live work center directly inside the page — no separate page to navigate to.
- The work center pulls from any workflow running in the system, not just Habitat workflows: pending approvals, assigned tasks, notifications, and mentions appear in one place.
- Duplicate navigation links removed; Launchpad now has one clear entry to My Work.

## If updating an existing site

Run `bench --site <site> migrate` to install the embedded work center block. Clear browser cache and hard-refresh after migration.

## 1.50.9

_New operational roles and permission updates._

- Maintenance technicians, cleaning supervisors, safety officers, and resident request coordinators now have dedicated app roles — your system administrator can assign the matching role profile to each team member.
- Any system user can now open a maintenance ticket directly; only the ticket owner can read and edit their own draft request.
- Internal auditors gain read and export access to custody, asset, movement, and lease records without operational write authority.

## If updating an existing site

Run `bench --site <site> migrate` to install the new roles and apply the updated permissions. Assign the new role profiles to team members via **User → Role Profile**.

## 1.50.8

_Shorter workspace names and security & reliability improvements._

- The main workspace is now called **Habitat Hub** instead of the longer previous name.
- Daily housing work lives under **Housing**, fire and cleaning safety checks under **Safety**, and app configuration under **Launchpad**.
- Security & reliability improvements.

## If updating an existing site

Run `bench --site <site> migrate` to apply the workspace rename. Any bookmarks or browser shortcuts to old workspace names will still work after the migration.

## 1.50.7

_A reliability fix in resident check-out._

- Checking the same resident out twice at the very same moment can no longer double-close their stay or duplicate the follow-up records.
- Nothing changes about how you record a check-out, or about the bed and room updates that follow.
- Existing check-outs are unaffected; the safeguard applies from now on.

## 1.50.6

_You can now give rooms a wing or block prefix when you generate a building._

- **Number rooms by wing or block.** Set a Room Number Prefix on any floor row and the generated rooms read like `JED1-1A05` (wing A) or `JED1-1B05` (wing B), so a room number tells you exactly where it is. Leaving the prefix blank keeps your existing numbering byte-for-byte unchanged.
- **Set the prefix right on the floor plan.** The prefix now appears in the floor-plan grid, so you can fill it in per floor without opening a dialog.
- **Your building code is now protected.** Once a building has rooms, its code can no longer be changed — renaming it would have orphaned every existing room. To change the code, remove the generated rooms first.

## 1.50.5

_Reliability fixes across custody returns, utility bills, and depreciation setup._

- A custody issue is now marked fully returned only when **every** issued article is actually back, not just when the quantities happen to add up.
- A utility bill is checked for duplicates within the **same company and building**, so the same account and period can still be billed correctly for each one.
- A depreciation policy must now have a **useful life greater than zero**, so a policy that would silently never depreciate can no longer be saved.

## 1.50.4

_You can now reach your own My Work page no matter your role._

- **Open to everyone signed in.** My Work is no longer limited to a fixed set of roles, so anyone with work waiting can open it.
- **Only your own work.** You still see just your pending approvals, assigned tasks, open submissions, recently closed items, and notifications, all on one screen.
- **A cleaner, personal view.** The old shared task list that mixed in everyone's tasks is gone; what is left is the work that belongs to you.

After updating, My Work opens for every signed-in user.

## 1.50.3

_Operations alerts that still need attention are no longer cleared by age._

- Only resolved alerts are aged out now, so an open or acknowledged alert is kept until someone handles it.
- How alerts are raised, acknowledged, and resolved stays exactly the same.
- Existing alerts are unaffected; the new rule applies from the next daily cleanup onward.

## 1.50.2

_Reliability fixes in the resident check-out and custody-damage flow._

- Checking a resident out with damaged or lost items now reliably opens a draft damage assessment.
- Amounts, ledgers, and who approves a payroll deduction stay exactly the same; deductions still arrive as a reviewable draft for HR.
- Nothing changes retroactively; the fixes apply to new check-outs going forward.

## 1.50.1

_Old asset depreciation snapshots are tidied away on their own._

- Submitted depreciation snapshots older than two years are cleared automatically, so the list stays lean without any manual cleanup.
- Nothing financial is touched: draft snapshots are always kept, and no ledger is ever changed.
- Existing data is untouched today; the two-year limit only applies to snapshots going forward.

## 1.50.0

_Your work inbox is now a full My Work Center — one screen for everything that's yours._

- **One screen for all your work.** My Work Center brings together your pending approvals, your assigned tasks, your open submissions, what closed in the last 48 hours, and your notifications — each in its own section.
- **Approve or reject without leaving the page.** Pending approvals show the available actions inline, so you can move a document forward in one click; the approval still runs through the standard Apex workflow, so who can approve never changes.
- **Close an assigned task in place**, or jump straight to any document from its row — every section links you right to the record.
- **Everything shown is strictly yours.** Each section reflects only your own documents and assignments, never another person's, even if you can otherwise read everything.

After updating, the page is titled My Work Center under My Work.
