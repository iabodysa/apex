# Apex Habitat 1.58

Workers and drivers now run pickups by QR, workers can request a ride for themselves, and the fleet alert list is one you can actually work.

- **A fleet alert list you can work, not just read.** Take ownership of an alert or assign it, snooze the ones that can wait, and see at a glance what is new since you last looked and what is overdue — with leaner one-row filters so the list stays scannable.
- **Board a trip by QR.** A worker shows a boarding pass on their phone and the driver scans it from the app, so the boarded count and the passenger list build themselves — and the driver can call any rider with one tap.
- **Workers can request a ride.** From the worker app a worker asks for transport for themselves, and can add extra travellers who are not registered yet by entering each name and ID — the request lands with the fleet desk to schedule.
- **The worker app keeps working offline.** When the signal drops the app shows the last information it saved, and it now reads in Urdu, Hindi, and Bengali alongside English and Arabic.
- **A refined look across portals and desk.** A new optional Atelier theme gives the portals an elevated finish, and the operator desk pages share one clean, consistent style.
