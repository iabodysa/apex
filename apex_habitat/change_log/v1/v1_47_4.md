# Apex 1.47.4

The Checkout Pending Clearance report now shows employee names.

## What changed for users

- **Checkout Pending Clearance** gained an **Employee Name** column, so clearance
  follow-up shows the person's name next to the raw Employee ID — matching the
  Active Resident Register, which already resolved names.
- Names are resolved in a single batched lookup, so the report stays fast.
- No change to filters, totals, or which checkouts are listed.

## If you are updating an existing site

- Run `bench migrate`. No data change.
