# Apex 1.47.4

The Checkout Pending Clearance report now shows the resident's name next to each ID.

## What changed

- **See who each clearance is for** — the Checkout Pending Clearance report gains an Employee Name column, so you can follow up by person instead of reading a raw ID.
- **Consistent with the resident register** — names now appear here the same way they already do in the Active Resident Register, so the two reports read alike.
- **Same list, same totals** — filters, totals, and which checkouts appear are unchanged. Only the new name column is added.
