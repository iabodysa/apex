# Apex 1.45.6

A small fix so the **My Work** workspace shows its sidebar icon.

## What changed for users

- **The My Work workspace icon now displays.** It previously used an icon name that
  does not exist in the Desk icon set, so the sidebar entry rendered with a blank icon.
- No other change — the workspace content and links are unchanged.

## What changed under the hood

- Set the My Work workspace `icon` to a valid Desk icon (`assign`, replacing the
  non-existent `todo`).
- Bumped the workspace `modified` timestamp so `bench migrate` re-imports the corrected
  definition.

## If you are updating an existing site

- Run `bench migrate`, then hard-refresh the Desk (the sidebar icon is cached client-side).
