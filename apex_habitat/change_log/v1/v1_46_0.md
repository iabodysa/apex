# Apex 1.46.0

The Housing Supervisor role is now scoped to the buildings he is responsible for.

## What changed for users

- **A Housing Supervisor (Resident Supervisor) now sees and acts only within his own building(s).**
  Assign a supervisor to one or more buildings (a User Permission on Accommodation Building), and from
  then on he can only:
  - **house residents** in those buildings (Accommodation Assignment),
  - **issue custody** from the store for those buildings (Custody Issue),
  - **oversee cleaning** for those buildings (Cleaning Log),
  - and he sees only those buildings in lists and links.
- One supervisor can cover **several buildings**. Oversight roles (Accommodation Manager, Internal
  Auditor, Finance Manager, System Manager) are not scoped and continue to see every building.

## What changed under the hood

- Added building-scoped `permission_query_conditions` + `has_permission` for Accommodation Assignment,
  Custody Issue, Cleaning Log, and Accommodation Building, mirroring the proven Salis fleet-supervisor
  project scope (`habitat/permissions.py`), with the building as the scope unit via a User Permission.
- A scoped supervisor with no building permissions sees nothing (must be assigned buildings first);
  building-less records are denied to scoped users. Covered by `tests/test_housing_supervisor_scope.py`.

## If you are updating an existing site

- Run `bench migrate`, then grant each Housing Supervisor a **User Permission on Accommodation Building**
  for each building they manage. Without any such permission a supervisor will see no housing records.
