# Apex 1.50.9

New operational roles and permission updates.


- Maintenance technicians, cleaning supervisors, safety officers, and resident request coordinators now have dedicated app roles — your system administrator can assign the matching role profile to each team member.
- Any system user can now open a maintenance ticket directly; only the ticket owner can read and edit their own draft request.
- Internal auditors gain read and export access to custody, asset, movement, and lease records without operational write authority.

## If updating an existing site

Run `bench --site <site> migrate` to install the new roles and apply the updated permissions. Assign the new role profiles to team members via **User → Role Profile**.
