## 1.31.0

_You can now issue, return, and assess custody for a worker who has arrived but is not yet registered — the same flexibility housing gained in the last release._

- **Hand custody to a passport-only arrival.** Custody issue, custody return, and damage assessment now let you track tools and equipment for a worker who is on a passport, not only for a registered Employee.
- **Nothing you already use changes.** Each custody record keeps its existing link to the responsible person, filled in for you, so current lists and reports keep working unchanged.
- **Consistent with the housing flow.** Custody now follows the same arrival path as accommodation, so a new worker can be both housed and equipped before their Iqama comes through.
