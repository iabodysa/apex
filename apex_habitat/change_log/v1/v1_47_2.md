# Apex 1.47.2

An internal permissions-audit tidy-up. No behavior change.

## What changed for users

- **No visible change.** This release only documents existing, intentional permission decisions in
  the code's audit trail.

## What changed under the hood

- Closed the Prompt 16 backlog item. The document-level permission checks it called for were already
  in place (the building-setup, work-order, and scheduled-task actions all verify
  `has_permission(..., doc=<doc>, throw=True)` on the specific record, not a blanket DocType role).
- Added `# audit-ok` markers to the three generator/ledger inserts that use `ignore_permissions`
  (safety-scope + scheduled-task-template generation, and the maintenance work-order completion ledger
  memo) — each is already gated by a document-level write check above it. Kept `ignore_permissions`
  deliberately: these are system-generated records, so granting users manual create permission on the
  templates would be broader than intended.

## If you are updating an existing site

- Run `bench migrate`. No data change.
