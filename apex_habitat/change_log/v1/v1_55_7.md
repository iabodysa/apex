# Masar nav, driver attendance fix, and instant app updates 1.55.7

Three fixes from live testing: a three-tab Masar bottom bar with secondary sections moved into Profile, a driver-attendance bug where checking in also stamped a check-out, and a service-worker switch so Masar shows the latest build immediately instead of a cached older version.

- Masar: bottom bar trimmed to Home, Transport, and Profile; accommodation, custody, and requests now open from a Profile 'More' section
- Driver attendance: checking in no longer also stamps a check-out, so a shift stays open until you check out; a zero-length day is refused
- Masar app now loads the latest build immediately while online (network-first shell) instead of a cached older version
