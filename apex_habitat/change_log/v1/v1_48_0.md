# Apex 1.48.0

Guided setup checklists now cover all three areas of Apex.


- **A new Apex Setup checklist** walks a new operator through the shared settings that accommodation and fleet both rely on, then points you to your work inbox — a clear first path after install.
- **A new Fuel Setup path in Salis** takes you step by step through setting a fuel quota, raising a fuel request, and processing a fuel claim, so consumption and spend stay reconciled from day one.
- **Salis now offers two guided journeys** — the original go-live setup and the new fuel path — so you can pick the start that matches what you need to do first.
- **Each checklist tracks its own progress**, so you always see which steps are done and which are still waiting for you.
