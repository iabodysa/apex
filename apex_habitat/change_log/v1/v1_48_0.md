# Apex 1.48.0

Balanced guided onboarding across all three modules.

## What changed for users

- **Apex Core now has a guided "Apex Setup" onboarding** — a four-step checklist
  to review the Apex Integration, Habitat, and Salis settings and open the Action
  Inbox, so a new operator has a clear post-install path (it complements the
  first-run Setup Wizard, it does not repeat it).
- **Salis gained a "Fuel Setup" onboarding path** (create a fuel quota, raise a
  fuel request, process a fuel claim) — Salis now offers two guided paths like the
  richer Habitat module, matching the standard ERPNext onboarding depth.
- Every new onboarding string is fully Arabic-translated.

## If you are updating an existing site

- Run `bench migrate` to load the new onboarding records. No data change.
