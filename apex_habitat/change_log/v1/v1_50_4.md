# Apex 1.50.4

Everyone now has their own My Work inbox.

## What changed for users

- The **Action Inbox** (My Work) is now open to **every signed-in user**, not a
  fixed set of roles. Each person still sees only their own pending approvals,
  tasks, and requests — so anyone with work waiting can now reach it.
- Removed the old **My Tasks** list from the My Work page: it showed everyone's
  open tasks instead of just yours. Your own tasks live in the Action Inbox.
- A clearer, personal view of what is waiting on you.

## If you are updating an existing site

- Run `bench migrate`.
