# Apex 1.45.1

Arabic coverage for the desk pages and operational messages (KB-audit M-12/13/14).

## What changed for users

- **Arabic-locale users now see the desk in Arabic.** 155 previously-English strings
  across the Action Inbox, Arrivals/Front desks, custody kiosk, transfer board,
  safety map, dispatch board and fuel console — plus server validation/error
  messages — are now translated.
- **No behavior change** — labels and messages only.

## What changed under the hood

- Added 155 deduped `source,Arabic` rows to `translations/ar.csv` (M-12 Action Inbox,
  M-13 desk pages, M-14 server `_()` messages); placeholders preserved; the
  comma-bearing dispatch-board subtitle is CSV-quoted. Run `bench build` + clear-cache.

## If you are updating an existing site

- Run `bench migrate`, then `bench build --app apex_habitat` and `bench clear-cache`.
