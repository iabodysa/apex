# Apex 1.47.1

A translation fix.

## What changed for users

- The "Gemini" option now shows an Arabic label (جيميني) instead of remaining in Latin script.

## What changed under the hood

- Added the missing Arabic value for the `Gemini` row in `translations/ar.csv`, which was breaking the
  release-hygiene check that requires every translation entry to carry an Arabic rendering.

## If you are updating an existing site

- Run `bench migrate` then `bench clear-cache`.
