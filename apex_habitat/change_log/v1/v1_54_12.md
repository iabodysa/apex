# Apex Habitat 1.54.12

A new /fleet web dashboard — the supervisor's own fleet board, now live.

- /fleet serves the fleet supervisor's exact dashboard design, with every vehicle, driver and custody record read live from the Salis DocTypes instead of a static file.
- Its actions update the real records: reassigning a driver, stopping a vehicle, sending it to or returning it from the workshop, recovering it, and reporting a theft.
- It opens for logged-in fleet roles only; the obsolete Save and Export buttons are gone because the data now lives in Apex.
