# Apex Habitat 1.55.18

A new home landing workspace, Arabic display fixes for the building dashboard and driver portal, custody damage-assessment alerts, and a new overdue-checkouts metric.

- Navigation: a new Apex Home landing workspace gathers the most-used actions, key metrics, the occupancy trend, and a live work queue on one default page.
- Building dashboard: floor labels now localize, so the Arabic interface shows Arabic floor names.
- Driver portal: trip and ticket status, category, and priority labels are now single-sourced and localized, with a coverage test that fails the build if an option is added or renamed without a translation.
- Custody: damage-assessment submissions now raise an alert (email and in-app bell) to the accommodation manager, including on already-installed sites.
- Housing: a new Overdue Checkouts metric card surfaces active assignments past their expected checkout date.
