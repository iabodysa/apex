# Apex 1.45.2

An under-the-hood maintenance release that consolidates how the app provisions its
default records. No user-facing behavior change.

## What changed for users

- **Nothing visible.** Every screen, record and default behaves exactly as before —
  this release only simplifies the machinery that creates the starter data on install.

## What changed under the hood

- Default Assignment Rules, Email Templates and Kanban Boards are now provisioned by a
  single data-driven seed loader instead of six separate hand-written seeder modules,
  which were retired.
- The loader now follows the Frappe core seeding idiom, and the Safety Task Catalog is
  provisioned create-only — a stale declaration that could have overwritten edited
  catalog entries on upgrade was removed, so your edits are always preserved.
- Older one-off upgrade steps that referenced the retired seeders were reduced to
  no-ops, and the seeding regression tests were streamlined to guard the data files.

## If you are updating an existing site

- Run `bench migrate`. No data migration is required — seeding is create-only, so your
  existing records and any edits you have made are left untouched.
