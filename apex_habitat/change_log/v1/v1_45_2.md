# Apex 1.45.2

Reliability improvements in how starter data is set up.


- **Setup is more consistent.** The default assignment rules, email templates and boards you start with on a new site are provisioned the same way every time.
- **Your edits are always preserved.** The safety task catalog and any changes you have made to starter records are never overwritten on update.
- **Existing data is unaffected.** This applies to fresh setup only; nothing already recorded is touched.
