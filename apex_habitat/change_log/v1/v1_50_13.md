# Apex Habitat 1.50.13

Room setup wizard: floor presets, per-floor code prefixes, and safe bed-capacity reduction.


- Floor presets (All Worker, Worker+Supervisor, Worker+Office/Storage, Driver, Mixed) and copy-floor-to-next to speed up building setup.
- Optional per-floor code prefix for room/bed numbers; building abbreviation locks once rooms exist to protect already-generated codes.
- Safe capacity reduction: empty surplus beds are retired to Out of Service after confirmation; rooms with occupied surplus beds are blocked instead of silently changed.
- Arabic translations added for all new room-setup strings.
