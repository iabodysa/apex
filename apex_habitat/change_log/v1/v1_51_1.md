# Apex Habitat 1.51.1

Apex 1.51.1 — Arrivals Desk floor & readiness fixes, a cost-center fallback on check-in, and the remaining production polish.

- Arrivals Desk: rooms on the Ground floor (floor 0) now group under "Ground Floor" instead of the "Unassigned Floor" bucket, basements label as "Basement N", and only rooms with no floor at all stay "Unassigned" — the regression came from treating floor 0 as falsy under the new functional floor_type scheme.
- Arrivals Desk: the un-assessed "Unknown" room-readiness state is no longer shown beside the bed count (it read as an error on freshly generated rooms); a readiness note now appears only for a real non-ready state and is translated.
- Check-in: a missing building-level cost center now falls back to the company's default cost center, so quick check-in is no longer hard-blocked when the building has none configured.
- Maintenance: an overdue maintenance ticket now raises a desk-visible Operations Alert under a new "Maintenance Overdue" alert type, instead of only writing a log line.
- Housekeeping: the Role Profile seeder commits roles before profiles install; maintenance materials seed from a single JSON source of truth; the building-license-expiring notification links its email template; Arabic translations added for the new floor and alert labels.
