# Apex Habitat 1.54.15

The Fleet dashboard is rebuilt the idiomatic Frappe way — a Vue single-page app — while keeping the supervisor's exact design.

- The /fleet board now runs as a Vue app (the fleet_portal portal, like /driver and /masar), reading and writing the same live Salis DocTypes through the same permission-gated API; the look is unchanged.
- Removed the obsolete version/date line and the dead Save / Export / WhatsApp buttons (Apex is the datastore), and added loading, empty (clear-filters) and error (retry) states.
- Added a subtle entrance animation, a keyboard focus ring and a reduced-motion option; the board stays responsive on phones and tablets.
- A signed-in user without a fleet role now sees a friendly "fleet role required" page instead of a raw 403; guests are still redirected to login.
