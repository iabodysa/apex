# Apex 1.50.10

My Work is now a universal work center for every system user.

## What changed

- Opening the My Work workspace now shows a live work center directly inside the page — no separate page to navigate to.
- The work center pulls from any workflow running in the system, not just Habitat workflows: pending approvals, assigned tasks, notifications, and mentions appear in one place.
- Duplicate navigation links removed; Launchpad now has one clear entry to My Work.

## If updating an existing site

Run `bench --site <site> migrate` to install the embedded work center block. Clear browser cache and hard-refresh after migration.
