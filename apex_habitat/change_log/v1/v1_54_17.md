# Apex Habitat 1.54.17

A Fleet dashboard reassignment fix from a security audit.

- Reassigning a driver on the Fleet board now fully succeeds or makes no change: if a concurrent reassignment wins the race, the second one is rejected cleanly instead of silently overwriting the vehicle's live driver and leaving an unsubmitted assignment behind.
- The reassign action now handles a blocked submit the same way the other Fleet actions already do.
- Found by an adversarial security audit of the /fleet feature (page, API and importer); the rest of the feature audited clean.
