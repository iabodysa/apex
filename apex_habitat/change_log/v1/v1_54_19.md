# Apex Habitat 1.54.19

The Fleet Control page and several fleet and housing surfaces now render fully in Arabic.

- The Fleet Control page no longer shows its export-count and open-incident labels in English — they are now translated like the rest of the board.
- 55 status, alert and action strings across the fleet and housing desk pages, the fuel console and settlement messages were added to the Arabic translations.
- A coverage test now fails the build if any fleet desk page or the `/fleet` portal adds a translate-call string without an Arabic entry, so new surfaces can't ship untranslated.
