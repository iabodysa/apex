# Apex Habitat 1.50.16

My Work: drop unscoped Quick Lists; keep number cards + Action Inbox shortcut (per-user correctness).

## What changed

- A Workspace Quick List filter cannot scope to the current user, so for privileged users it showed everyone's tasks/records on a personal My Work page.
- My Work now ships native number cards + a shortcut to the Action Inbox page, which is correctly per-user scoped (uses session.user).
- Updated My Work workspace tests to the native design (no custom block; Action Inbox shortcut required; no quick lists).
