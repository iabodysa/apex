# Apex Habitat 1.54.27

Safety Rounds for building safety checks, plus a cleaner Fleet board.

- New Safety Round: group a building's safety-task checks for one cadence (daily, weekly, monthly, and so on) into one submittable round that derives a Pass, Needs Attention, or Fail result.
- New Safety Round Compliance report shows, per task, the latest status and what still needs attention for a chosen building and period.
- The old Safety Inspection Report is retired in place (hidden and read-only); existing records are kept and new work uses Safety Rounds.
- The Fleet dashboard now uses a clean professional Lucide icon set instead of emoji.
