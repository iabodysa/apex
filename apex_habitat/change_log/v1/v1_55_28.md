# Apex Habitat 1.55.28

A one-click departure-transport hand-off from a resident check-out, in-app alerts for drivers, a server-side fleet export, the Arrival Batch on the Housing workspace, and right-to-left polish on the Front Desk board.

- **Departure transport from a check-out.** When you complete a Final Exit or End of Contract check-out, an **Arrange Departure Transport** button raises the relocation transport for that worker in one step and links it back to the check-out. It only appears for those two reasons, and asking twice reuses the same request rather than creating a duplicate.
- **In-app alerts for drivers.** A driver is now notified in the app when their own clearance is blocked, and the current driver of a vehicle is alerted when that vehicle's compliance is expiring soon — alongside the existing alerts to fleet supervisors.
- **Fleet export of the full filtered list.** **Export CSV** on the Fleet Control board now builds the file on the server from your current filters, so it contains every vehicle you are allowed to see — not only the rows currently on screen.
- **Arrival Batch on the Housing workspace.** The pre-arrival manifest (Arrival Batch) now has its own link in the Housing workspace, so you can open it directly instead of searching for it.
- **Front Desk reads right-to-left.** The Front Desk bed board now mirrors cleanly in Arabic, with floor and bed headings shaped correctly instead of forced upper-case spacing.
- **Tidier asset-movement form.** The system section on the asset-movement form is now collapsed by default, keeping the everyday fields in view.
