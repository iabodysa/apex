## 1.16.0

_One Apex Core workspace now gathers all of your configuration and admin tools in a single place._

- **Everything admin in one workspace.** The shared settings, the Habitat setup masters, the Habitat console (engines, ledgers, logs, and alert counts), and the Salis setup masters are now gathered into a single Apex Core workspace, organized into clear sections.
- **Less sidebar clutter.** The three separate workspaces for Habitat setup, the Habitat console, and Salis setup are gone, and all of their links, shortcuts, and cards are carried over into Apex Core.
- **One predictable home for both modules.** Habitat and Salis configuration now sit side by side, so there is a single place to administer both.

After updating, your admin tools all appear under the Apex Core workspace in the sidebar.
