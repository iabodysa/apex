# Apex Habitat 1.50.24

Room Setup: floor_type now drives floor numbering (B/G/R), not a cosmetic label.

## What changed

- Basement rooms get B-codes (below ground), Ground = G, Roof = R, middle floors stay numeric (e.g. JED1-B101 / JED1-G01 / JED1-201 / JED1-R01).
- Floors are ordered bottom-to-top by type (Basement -> Ground -> Middle -> Roof) in both the generator and the wizard.
- The Room Setup wizard shows the functional floor code per floor block.
