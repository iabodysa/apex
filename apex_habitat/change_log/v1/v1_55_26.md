# Apex Habitat 1.55.26

Arrival-lifecycle alerts on the pre-arrival manifest, clearer fleet empty and access states, critical operations alerts routed to the project's supervisor, and a deduction-status indicator on damage assessments.

- Housing: the pre-arrival manifest now drives a set of arrival-lifecycle alerts — an expected-arrivals-today heads-up, a not-yet-reconciled reminder when workers remain unhoused after the date, and a notice when an over-capacity bed is created.
- Fleet: the fleet board now tells an empty result apart — distinguishing "no projects are assigned to you" from a genuinely empty fleet — so an access gap reads differently from an empty board.
- Fleet: a critical operations alert now reaches the supervisor of the vehicle's own project, instead of only the general team.
- Housing: a custody damage assessment now shows a live indicator of its salary-deduction status — not created, draft, submitted, paid, or cancelled.
