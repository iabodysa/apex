# Apex Habitat 1.60.49

Boarding self-confirm with driver exception override, a Salis Settings alert-aging section, and a setup wizard that configures all Apex settings.

- Workers now self-confirm boarding with one tap; the driver no longer approves each rider and intervenes only for exceptions.
- The boarding manifest headcount now counts self-confirmed riders, and the driver can reset a mistaken boarding with a single tap.
- Added an Alert Aging SLA (Hours) section to Salis Settings, grouping the alert-aging thresholds.
- The first-install setup wizard now configures all Apex settings (company, accounting, notifications, fleet, and deductions) across three guided slides.
