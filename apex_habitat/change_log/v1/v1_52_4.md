# Apex Habitat 1.52.4

Apex 1.52.4 — security hardening on three endpoints, native-first cleanups, a floor-numbering guard, and the Arabic translation backlog cleared.

- Security: closed a catalog leak on the custody kiosk (the full Custody Article list was readable without a permission check), and gated the Temporary Worker passport/iqama PII and the Masar token secret on the arrival slip, plus the Maintenance Request read on Work Order creation, behind explicit permission checks.
- Security: the temporary-worker party-repoint UPDATE now validates its table and column identifiers against an allowlist pattern before building the SQL.
- Native-first: replaced three hand-rolled "users holding role X" queries with `frappe.utils.user.get_users_with_role`; replaced manual ToDo creation in the idle-resident report with the native `frappe.desk.form.assign_to.add` (so the desk Assigned-To panel and assignee notifications work); the supplier cost-recovery report now defaults its month/year from the server date instead of the browser clock.
- Bug fix: the room generator now rejects two floor-plan rows that resolve to the same floor code — previously a Ground floor and a Middle floor both at number 0 collided and silently dropped one floor's rooms.
- Arabic: cleared the translation backlog (35 strings translated, format placeholders preserved).
