# Apex 1.11.0

Fuel requests now follow a clear approval path, so every request gets a genuine second look.


- **One clear path for all fuel.** Every fuel request — a standard order, a quota top-up, or a fuel-chip action — moves through **Pending, Approved, Done**, with a clear status at each step and a clean reject path back. No more silent status changes.
- **The raiser cannot approve their own request.** Approval is reserved for fleet managers, so each request gets a real second pair of eyes before anything is committed.
- **Quotas stay accurate.** A vehicle's allowance updates only when a standard request is approved, and reverses if the request is cancelled — so the quota always matches what was actually approved.
- **The Fuel Approval Console stays in step.** What you approve or reject in the console and what the request shows are always the same, with no mismatch to chase.

After updating, fuel requests move only through their approve and reject buttons.
