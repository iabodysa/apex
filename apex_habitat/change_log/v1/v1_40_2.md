# Apex 1.40.2

Module-artifact hygiene from the KB-grounded audit (round-trip integrity) plus a
background-job dedup fix.

## What changed for users

- **No user-visible change.** This is internal hygiene: dashboard/number-card
  definitions now round-trip cleanly to source, and the nightly cost-allocation
  jobs de-duplicate correctly.

## What changed under the hood

- Audit BLOCKERs B-1/B-2/B-3: stamped `is_standard=1` (+ a real `modified`) on 115
  Number Card / Dashboard Chart JSONs (habitat + salis) so `bench migrate` re-imports
  them and developer-mode edits export back — closing the one-way export ratchet.
  Also bumped the null `modified` on 17 notification JSONs.
- Audit M-5: `daily_accommodation_cost_allocation` now enqueues with
  `job_id=... , deduplicate=True` instead of the deprecated `job_name=` (which gave
  no real dedup), so a scheduler lag can't double-enqueue a building.

## If you are updating an existing site

- Run `bench migrate`, then `bench build` and `bench clear-cache`.
