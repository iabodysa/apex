# Apex Habitat 1.55.22

Clearer fleet-control empty states, checkout reminders that reach the building supervisor, truthful fleet incident panels, a supervisor buildings-portfolio endpoint, and a Housing live-occupancy metric row.

- Fleet: the fleet control board now tells a "no project assigned" account apart from an over-filtered no-match, guiding the user instead of showing one blank message for both.
- Housing: expected-checkout reminders now also reach the building's own responsible supervisor, so the alert lands with the person accountable for that facility.
- Fleet: the vehicle Damages, Accidents, and Stolen panels now show real records instead of always appearing empty.
- Housing: a new read-only endpoint returns the caller's allowed buildings with a server-computed bed mix for a Front Desk portfolio header.
- Housing: a new Live Occupancy row on the Housing workspace surfaces total occupancy, vacant beds, imminent checkouts, and open resident requests at a glance.
