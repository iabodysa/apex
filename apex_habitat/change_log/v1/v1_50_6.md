# Apex 1.50.6

You can now give rooms a wing or block prefix when you generate a building.

## What changed

- **Number rooms by wing or block.** Set a Room Number Prefix on any floor row and the generated rooms read like `JED1-1A05` (wing A) or `JED1-1B05` (wing B), so a room number tells you exactly where it is. Leaving the prefix blank keeps your existing numbering byte-for-byte unchanged.
- **Set the prefix right on the floor plan.** The prefix now appears in the floor-plan grid, so you can fill it in per floor without opening a dialog.
- **Your building code is now protected.** Once a building has rooms, its code can no longer be changed — renaming it would have orphaned every existing room. To change the code, remove the generated rooms first.
