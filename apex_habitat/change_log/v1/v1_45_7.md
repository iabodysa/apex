# Apex 1.45.7

A low-risk hygiene sweep — dead-code removal, audit markers, English-only release notes,
and a workspace-card metadata fix. No behaviour change.

## What changed for users

- **No visible change.** This release only tidies internal code and metadata.
- The "Unresolved Alerts" card is now correctly filed under the Habitat module (it had a
  blank module), so it groups properly in card pickers.

## What changed under the hood

- Removed dead code: an unreachable `custody_cleared = 0` assignment immediately before a
  `frappe.throw` (Accommodation Checkout) and an always-false `if not doc.doctype` guard
  (Accommodation Ledger).
- Added `# audit-ok` rationale markers to the three legitimate `ignore_permissions` inserts
  (scheduler cost-allocation ledger, scheduler task-instance generation, guest QR web-form
  intake) so the permissions audit trail is explicit.
- Replaced the two inline Arabic fragments in the English changelog feed titles with English
  (the desk feed text is English-only; Arabic lives in translation files).
- Set the "Unresolved Alerts" Number Card `module` to "Habitat".

## If you are updating an existing site

- Run `bench migrate`. No data migration required.
