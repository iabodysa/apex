# Apex 1.37.0

A live "Pending My Action" count on the Apex Core workspace — see at a glance how
many documents await your action, then open the Action Inbox to act on them.

## What changed for users

- **A personal count card.** A new "Pending My Action" number card sits at the top
  of the Apex Core workspace under a "My Work" heading. It shows, per user, how
  many documents are waiting on you right now — the workflow approvals you can act
  on plus the tasks assigned to you.
- **One click to act.** The card complements the existing Action Inbox page (still
  reachable from its shortcut): the card is the at-a-glance number, the page is
  where you Approve/Reject in place.
- **Always your own number.** The count is computed per user from the same scoped
  sources as the inbox, so everyone sees only their own pending work.

## What changed under the hood

- New whitelisted `apex_core.action_inbox.get_pending_action_count` reuses
  `get_pending_actions` (same native scoping + staleness guard) and returns
  `{value: N}` for a native Custom Number Card.
- New `is_standard` Number Card `Pending My Action` (module Apex Core) imported by
  `bench migrate`; wired into the Apex Core workspace content + `number_cards`.
- Labels `Action Inbox`, `My Work`, `Pending My Action` added to `ar.csv`.

## If you are updating an existing site

- Run `bench migrate`, then `bench build` and `bench clear-cache`.
