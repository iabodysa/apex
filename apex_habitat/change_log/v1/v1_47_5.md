# Apex 1.47.5

An internal metadata tidy-up. No behavior change.

## What changed for users

- **No visible change.** This release only corrects internal file timestamps.
- Three shipped definitions (Accommodation Building, Accommodation Site, and the
  Habitat workspace) carried a future `modified` date. Future-dated metadata can
  make `bench migrate` skip re-importing a later real edit, so the timestamps are
  normalized to the present.
- A release-hygiene test now fails CI if any shipped definition is ever future-dated again.

## If you are updating an existing site

- Run `bench migrate`. No data change.
