# Apex Habitat 1.60.12

A mobile Housing Inventory count portal for field supervisors, and asset custody sign-off now moves the custodian.

- Housing Inventory count portal at /housing-count: pick a building, count each item line by room, and submit from a phone; the building scope confines each supervisor to their own estate.
- Field supervisors can now record an inventory count directly, with the counted-versus-expected variance derived on the server.
- Fixed asset custody assignment now updates the asset's custodian on sign-off (it was a sign-off only before), and restores the prior custodian if the assignment is cancelled.
