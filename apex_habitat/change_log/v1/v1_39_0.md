# Apex 1.39.0

The nightly accommodation cost run is faster and stays out of the way.


- **Quicker overnight costing.** The daily accommodation cost run now spreads its work across buildings instead of one long job, so the system stays responsive.
- **Same amounts, by design.** Every per-person daily share and cost row is identical to before; only the speed of the run changed.
- **Safe to repeat.** Running a day again never doubles a cost that was already posted, and existing records are untouched.
