# Apex Habitat 1.54.5

Closes a finance-approval bypass in payment routing: a real payment can only be created from a request the finance team actually approved.

- A payment request now counts as finance-approved only from the server-recorded approver stamped during the finance-approval step, never from its editable status field, so setting a request's status to "Paid" or "Approved by Finance" outside the approval step can no longer trigger a real payment.
- That approver record is now owned by the server: only the finance-approval step can write it (after the finance-role and segregation-of-duties checks), so it can no longer be set or forged when a request is created or edited.
- The approver is recorded on entry to every finance-gated state (both "Approved by Finance" and "Paid"), so an approved or paid request always carries the proof that finance cleared it.
