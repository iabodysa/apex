# Apex Habitat 1.52.5

Apex 1.52.5 — dashboards now provision the native Frappe way (is_standard module JSON, like ERPNext) instead of Python seeders.

- The 11 app dashboards (Habitat + Salis) now ship as native is_standard module JSON files — the same mechanism ERPNext uses for its own dashboards — auto-synced on install and migrate, instead of being hand-built by three Python seeders at runtime.
- Removed the double-provisioning where the Salis seeders re-created Dashboard Charts and Number Cards that already ship as module JSON (and flipped them to non-standard on every run).
- The three dashboard seeders are retired to documented no-op stubs; a one-time patch drops the old non-standard Dashboard records so migrate re-imports them natively.
- No dashboard was lost — every chart and number card was shipped as is_standard JSON, including the recovered Salis Finance Manager and Movement Operations dashboards; the workspace-linked Movement Operations dashboard resolves correctly.
