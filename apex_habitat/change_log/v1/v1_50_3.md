# Apex 1.50.3

Operations Alerts that still need attention are no longer cleared by age.

## What changed for users

- The daily housekeeping job that trims old **Operations Alerts** now only ages
  out **Resolved** alerts. An **Open** or **Acknowledged** alert is still
  actionable, so it is **kept indefinitely** — previously any alert older than
  the retention window was deleted regardless of its status, which could quietly
  remove alerts no one had handled yet.
- The retention clock for a Resolved alert now counts from when it was actually
  **resolved** (falling back to its last-modified date for older records), so an
  alert is only cleared a full retention period after it was closed.
- No change to how alerts are raised, acknowledged, or resolved — only to which
  ones the cleanup job is allowed to remove.

## If you are updating an existing site

- Run `bench migrate`. The new rule applies on the next daily cleanup; no
  unresolved alerts are removed.
