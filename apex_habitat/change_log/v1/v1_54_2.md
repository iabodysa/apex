# Apex Habitat 1.54.2

Security and accommodation fixes: routed-payment permission recheck plus new security CI gates, the Site as the single building-address source, derived building capacity, a Habitat Hub onboarding step, and a model cleanup.

- Routed-payment endpoint now rechecks source write and submit permission before any side effect, closing an authorization bypass; added SQL-interpolation, write-permission, and secret-scan CI gates.
- Accommodation Site is now the single source of truth for a building's address; the building shows it read-only, ending duplicate address entry.
- Building total capacity now derives from its rooms' bed capacity.
- The Habitat Hub landing workspace now carries the Accommodation Go-Live onboarding.
- Removed an unused depreciation-policy field and its stale dashboard back-link.
