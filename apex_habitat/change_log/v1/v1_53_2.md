# Apex 1.53.2

Five core forms re-laid-out for clarity (council-reviewed).

- Five core forms — Accommodation Assignment, Checkout, Lease, Maintenance Request, and Custody Issue — were re-laid-out for clarity: fields grouped by purpose, audit and system fields isolated in collapsed System tabs, and short fields packed into denser columns.
- Long values (notes, tables, attachments) now take their own full-width rows instead of being cramped beside short fields.
- The forms behave identically and simply read better. One exception to layout-only: Accommodation Checkout's sensitive financial fields (cost centre, damage deduction, linked additional salary) were also gated to a higher permission level (permlevel), so only authorised roles see them.
