# Apex 1.50.5

Reliability fixes across custody returns, utility bills, and depreciation setup.


- A custody issue is now marked fully returned only when **every** issued article is actually back, not just when the quantities happen to add up.
- A utility bill is checked for duplicates within the **same company and building**, so the same account and period can still be billed correctly for each one.
- A depreciation policy must now have a **useful life greater than zero**, so a policy that would silently never depreciate can no longer be saved.
