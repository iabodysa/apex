# Apex Habitat 1.55.6

Masar is now an installable, offline-capable app (PWA).

- Masar: you can install it to your home screen and open it like a native app.
- Masar: it works offline, keeping the app shell and your last-known info when there is no connection.
- Masar: it loads its shell from a local cache, so it opens fast and no longer depends on the network or an external font CDN.
