# Apex 1.40.1

The "My Work" workspace is now a fuller hub.

## What changed for users

- **"My Work" shows your tasks inline.** Beyond the "Pending My Action" count and
  the Action Inbox shortcut, the workspace now lists your open tasks (a "My Tasks"
  quick list) and adds a shortcut to your Maintenance Requests — so the page you
  land on is a real personal work hub, not just a counter.

## What changed under the hood

- `My Work` workspace gains a `ToDo` quick list (filter `status = Open`; ToDo's own
  permission scopes it to the signed-in user) and a `Maintenance Request` shortcut,
  alongside the existing card + Action Inbox page shortcut. Labels added to ar.csv.

## If you are updating an existing site

- Run `bench migrate`, then `bench build` and `bench clear-cache`.
