# Apex 1.45.3

A small fix release that ensures the Movement (Salis) dashboards are ready the
moment the app is installed, instead of only appearing after the first upgrade.

## What changed

- The Movement role dashboards — Fleet Manager, Fleet Supervisor, Finance, the two
  divisional views and the Movement operations overview — now appear immediately on a
  brand-new installation, rather than only after the first update.
- Their number cards and charts (vehicle status, fuel cost, trip fulfilment, rental
  accruals, driver attendance and related metrics) are provisioned during install, so
  the Movement workspace is fully populated from day one.
- The provisioning stays fully repeatable: re-running it never creates duplicate cards,
  charts or dashboards, and any tiles you have customised are left untouched.

## If you are updating an existing site

- Run `bench migrate`. Nothing changes for sites that were already up to date — this
  release only closes a gap that affected fresh installations.
