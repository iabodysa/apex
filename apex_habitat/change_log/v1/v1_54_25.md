# Apex Habitat 1.54.25

A building's supervisor field now drives that supervisor's building access.

- Setting the Responsible Facility Supervisor on an Accommodation Building automatically grants that user the building-scoped User Permission.
- Changing the supervisor moves the access to the new person and removes it from the previous one; clearing the field removes it.
- Building access now follows the supervisor field as the single source of truth, instead of maintaining a separate permission by hand.
