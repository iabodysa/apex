# Apex 1.50.8

Shorter workspace names and security & reliability improvements.


- The main workspace is now called **Habitat Hub** instead of the longer previous name.
- Daily housing work lives under **Housing**, fire and cleaning safety checks under **Safety**, and app configuration under **Launchpad**.
- Security & reliability improvements.

## If updating an existing site

Run `bench --site <site> migrate` to apply the workspace rename. Any bookmarks or browser shortcuts to old workspace names will still work after the migration.
