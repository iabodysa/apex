# Apex Habitat 1.51.0

Apex 1.51.0 — Room Setup wizard, native My Work, building Address/Maps/Connections/floor-dashboard, and a batch of production fixes.

- Room Setup: new staged wizard page (floors -> room types -> beds -> approve); floor_type now drives room numbering (Basement=B, Ground=G, Roof=R) and ordering; the old preset/table flow was removed.
- My Work: rebuilt with native widgets — number cards, scoped Quick Lists (Pending Approvals / My Tasks / Mentions), and an Action Inbox shortcut; the non-rendering shadow-DOM block was retired.
- Accommodation Building: native Address widget, clickable Google Maps link, grouped Connections (Rooms/Beds/Leases/Residents...), and a new CPU-efficient floor-layout dashboard; Floor Plan grid is read-only (wizard-managed).
- Fixed building Connections not rendering (the form dashboard reset was hiding them).
- Production: Role Profiles now install via exported fixtures; Driver permission rows no longer duplicate on every migrate; dashboard seeders preserve admin-added tiles; System Manager now sees every workspace.
- Notifications: removed the dead notification-channel setting and dropped System Manager from operational notification recipients.
- Fixed a stale Salis workspace link; Arabic translations added for all new UI; changelog entries cleaned up.
