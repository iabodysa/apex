# Apex Habitat 1.51

Apex 1.51.0 — Room Setup wizard, native My Work, building Address/Maps/Connections/floor-dashboard, and a batch of production fixes.

## 1.51.1

_Apex 1.51.1 — Arrivals Desk floor & readiness fixes, a cost-center fallback on check-in, and the remaining production polish._

- Arrivals Desk: rooms on the Ground floor (floor 0) now group under "Ground Floor" instead of the "Unassigned Floor" bucket, basements label as "Basement N", and only rooms with no floor at all stay "Unassigned" — the regression came from treating floor 0 as falsy under the new functional floor_type scheme.
- Arrivals Desk: the un-assessed "Unknown" room-readiness state is no longer shown beside the bed count (it read as an error on freshly generated rooms); a readiness note now appears only for a real non-ready state and is translated.
- Check-in: a missing building-level cost center now falls back to the company's default cost center, so quick check-in is no longer hard-blocked when the building has none configured.
- Maintenance: an overdue maintenance ticket now raises a desk-visible Operations Alert under a new "Maintenance Overdue" alert type, instead of only writing a log line.
- Housekeeping: the Role Profile seeder commits roles before profiles install; maintenance materials seed from a single JSON source of truth; the building-license-expiring notification links its email template; Arabic translations added for the new floor and alert labels.

## 1.51.0

_Apex 1.51.0 — Room Setup wizard, native My Work, building Address/Maps/Connections/floor-dashboard, and a batch of production fixes._

- Room Setup: new staged wizard page (floors -> room types -> beds -> approve); floor_type now drives room numbering (Basement=B, Ground=G, Roof=R) and ordering; the old preset/table flow was removed.
- My Work: rebuilt with native widgets — number cards, scoped Quick Lists (Pending Approvals / My Tasks / Mentions), and an Action Inbox shortcut; the non-rendering shadow-DOM block was retired.
- Accommodation Building: native Address widget, clickable Google Maps link, grouped Connections (Rooms/Beds/Leases/Residents...), and a new CPU-efficient floor-layout dashboard; Floor Plan grid is read-only (wizard-managed).
- Fixed building Connections not rendering (the form dashboard reset was hiding them).
- Production: Role Profiles now install via exported fixtures; Driver permission rows no longer duplicate on every migrate; dashboard seeders preserve admin-added tiles; System Manager now sees every workspace.
- Notifications: removed the dead notification-channel setting and dropped System Manager from operational notification recipients.
- Fixed a stale Salis workspace link; Arabic translations added for all new UI; changelog entries cleaned up.
